# Week 3 references

Official sources checked on 26 October 2026. Source numbers match the PDF guides. Lab specifications come from the supplied Week 3 activity sheet.

1. **Canonical. [Ubuntu Server download](https://ubuntu.com/download/server).** Current LTS download: Ubuntu Server 26.04.1 LTS, amd64.

2. **Canonical. [Basic installation](https://ubuntu.com/server/docs/tutorial/basic-installation/).** Installation preparation and official server documentation.

3. **Canonical. [Subiquity screen-by-screen installer walk-through](https://canonical-subiquity.readthedocs-hosted.com/en/latest/tutorial/screen-by-screen.html).** Installer screens, storage, profile and SSH options.

4. **Oracle. [VirtualBox User Guide, Release 7.2](https://docs.oracle.com/en/virtualization/virtualbox/7.2/user/EN-VBOX-7-2-USER.pdf).** VM creation, EFI, networking and NAT forwarding.

5. **Canonical. [OpenSSH server](https://ubuntu.com/server/docs/how-to/security/openssh-server/).** SSH installation, configuration and validation.

6. **Canonical. [Install and manage packages](https://ubuntu.com/server/docs/how-to/software/package-management/).** APT package installation and updates.

7. **UEFI Forum. [UEFI FAQs](https://uefi.org/faq).** Firmware interfaces, boot support and Secure Boot.

8. **Microsoft Learn. [Convert a disk to GPT or MBR partition scheme](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-disk-partition-scheme).** MBR limitations and GPT capabilities.

9. **Microsoft Learn. [Windows and GPT FAQ](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/windows-and-gpt-faq?view=windows-11).** UEFI/GPT relationships and Windows-specific limitations.

10. **GNU Project. [GNU GRUB Manual](https://www.gnu.org/software/grub/manual/grub/grub.html).** Bootloader, Linux kernel and initial RAM disk.

11. **systemd project. [bootup](https://www.freedesktop.org/software/systemd/man/bootup.html).** System manager, services and boot targets.

12. **Microsoft. [Windows Server 2025 Evaluation Center](https://www.microsoft.com/en-in/evalcenter/evaluate-windows-server-2025).** 180-day evaluation and internet activation guidance.

13. **Microsoft Learn. [Install Windows Server from installation media](https://learn.microsoft.com/en-us/windows-server/get-started/install-windows-server).** Installation and Desktop Experience selection.

14. **Microsoft Learn. [Windows Server hardware requirements](https://learn.microsoft.com/en-us/windows-server/get-started/hardware-requirements).** Check CPU, memory, storage and firmware compatibility.

15. **Rocky Linux. [Installing Rocky Linux 10](https://docs.rockylinux.org/10/guides/installation/).** Rocky Linux as an enterprise Linux server platform.

16. **Rocky Linux. [DNF package manager](https://docs.rockylinux.org/10/guides/package_management/dnf_package_manager/).** RPM/DNF package management.

17. **Rocky Linux. [SELinux Security](https://docs.rockylinux.org/10/guides/security/learning_selinux/).** SELinux policies and enforcing mode.

18. **Canonical. [AppArmor](https://ubuntu.com/server/docs/how-to/security/apparmor/).** Ubuntu application confinement.

19. **Microsoft Learn. [Comparison of Windows Server editions](https://learn.microsoft.com/en-us/windows-server/get-started/editions-comparison).** Windows server roles and security features.

20. **Oracle. [VirtualBox downloads](https://www.virtualbox.org/wiki/Downloads).** Official host installer; use the Windows hosts download.
